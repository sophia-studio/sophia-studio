# Sophia Studio — versiones

**Sophia Studio** es un programa de diseño CAD paramétrico para Windows, de [CreaLab](https://crea-lab.cl). Permite pasar de un boceto 2D a piezas 3D exactas y automatizar el diseño con nodos y reglas, sin escribir código.

Este repositorio publica **solo los instaladores** de cada versión. El código fuente no es público.

## Descargar

➡️ **[Descargar la última versión](https://github.com/sophia-studio/sophia-studio/releases/latest)**: en la página, el archivo `SophiaStudio-<versión>.exe` de la sección *Assets*.

Las versiones anteriores, con sus notas de cambios, están en **[todas las versiones](https://github.com/sophia-studio/sophia-studio/releases)**.

> Windows puede mostrar un aviso de SmartScreen la primera vez («Windows protegió su PC»). Para continuar, usa **Más información → Ejecutar de todas formas**.

## Requisitos

- Windows 10 u 11 de 64 bits.
- Conexión a internet para iniciar sesión. Después, la app funciona sin conexión unos días.
- Una cuenta de Sophia Studio. Se crea desde la propia app o en [sophiastudio.crea-lab.cl](https://sophiastudio.crea-lab.cl).

La instalación no pide permisos de administrador: se instala para tu usuario de Windows.

## Qué incluye

- **Boceto 2D con restricciones reales**: líneas, arcos, círculos, ranuras, cotas inteligentes y patrones.
- **Modelado 3D exacto (BRep)**: extrusión, revolución, operaciones booleanas y empalmes, con previa en vivo, deshacer y rehacer.
- **Superficies** con continuidad G1 y G2 y NURBS racionales, editables con tiradores.
- **Parámetros y fórmulas con unidades**, compartidos entre bocetos, piezas y tablas Excel, CSV o SQLite.
- **Aplicaciones**: un editor visual de nodos y reglas para automatizar diseños y crear formularios con varias ventanas, que se publican como botones en la cinta.
- **Derivación** de piezas entre documentos, con vínculos y propagación de cambios.
- **Autoguardado y recuperación** después de un cierre inesperado.

## Actualizaciones

La app busca versiones nuevas sola, la descarga en segundo plano y te pide actualizar con **Guardar y actualizar**: primero guarda tu proyecto y luego se reinicia en la versión nueva.

Cada versión va firmada digitalmente y la app comprueba la firma. Si un archivo no viene de este repositorio o fue modificado, no lo instala.

## Reportar un problema

En la app, el botón **Reportar** de la barra de título envía al equipo una captura y los pasos recientes.
Antes de enviarse, el reporte se limpia de datos personales: rutas, nombres de usuario y equipo, correos e IP.
Para cualquier otra consulta, usa [Soporte en tu cuenta](https://sophiastudio.crea-lab.cl/app/support).
